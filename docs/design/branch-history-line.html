What this is

A layout option in the existing Diffview chrome. For strip, column, and tree tab, graph is a third IconButton on the style bar, same 32px small size as split and unified. For right, popover, and top, the trigger is a 40px IconButton in the title bar, after Refresh and before Settings. Split and unified stay on the style bar. Workspaces, title, compare trigger, file tree, and hunk pane stay as they are.

What the graph answers

Two lanes from the merge-base. The ahead lane is commits reachable from head and not from base (--state-success). The behind lane is commits reachable from base and not from head (--state-danger). Merge-base is the diamond in --state-merge. Working tree, when live, is a hollow node in --state-info.

Linear: behind is empty, merge-base is the base tip. Diverged: both lanes have commits. Behind: ahead is empty. In sync: head, base, and merge-base are one commit.

Placements

Strip. Graph on expands a 68px inset row under the style bar, same surface as the workspaces column. The diff stays full width. Toggle is on the style bar.

Column. Graph on opens a 196px column between the file tree and the diff, with the same splitter language and the 400ms workspaces curve. Toggle is on the style bar.

Tree tab. Files | Graph in the existing tree column, using the Review segment control. No new chrome. Toggle is on the style bar.

Right. Graph on opens a 220px column after the diffs. File tree and hunk stay put. Toggle is the title-bar button next to Settings.

Popover. The same title-bar button opens a 280px overlay from the top right. Diff layout does not shift.

Top. The same title-bar button expands a 72px strip under the title bar, above the file tree and diffs.

Settings

Review keeps the Split and Unified cards. Graph is a separate row because it is independent: split with graph on, unified with graph off.
